# InertiaX Community

Welcome to the public community space for [InertiaX](https://inertiax.dev).

InertiaX is a backend-driven UI framework for building rich application interfaces while keeping behavior and configuration close to your backend.

This repository does not contain the InertiaX source code. It exists as a home for community discussions, questions, ideas, feedback, and announcements.

## Discussions

Use [GitHub Discussions](../../discussions) to:

- 💬 Ask questions about using InertiaX
- 🧪 Share Early Access feedback
- 💡 Suggest features and improvements
- 🛠️ Show what you're building
- 📣 Follow project announcements and releases

If you're participating in Early Access, feedback about confusing APIs, missing functionality, documentation issues, or things that required more work than expected is especially valuable.

## Bugs

If you believe you've found a bug, start a discussion with enough information to reproduce the problem.

Please avoid posting private credentials, access tokens, license keys, or sensitive application code publicly.
